# Project Operating Notes — NVIDIA Nemotron Reasoning Challenge

## Codex meta-prompt response style

Whenever ChatGPT shares a meta-prompt intended for Codex, first provide a short K-12 summary of what the prompt is asking Codex to do.

Required format:

1. **K-12 summary first**
   - Explain in simple terms what Codex will change or build.
   - Use plain language and a short analogy if helpful.
   - Keep it concise.

2. **Then the Codex meta-prompt**
   - Provide the full implementation prompt.
   - Keep it specific, file-oriented, and reproducible.
   - Include validation commands, commit message, and push instructions when relevant.

This applies across sessions and new chats for this project.
