## Current hypotheses after today
1. **Bit data is valuable but current traces are too compact.**
   - Current traces use compact lock lines like `B0:AND(1,2)->1`.
   - A better trace may need bit-serial steps such as `AND(1,1)=1`.

2. **Full-text loss is likely inefficient.**
   - Notebook B still trains on the whole chat text.
   - Assistant-only loss should likely be the next training improvement.

3. **Memory budget is tight.**
   - `MAX_SEQ_LEN=512` OOMed.
   - `MAX_SEQ_LEN=384` remains the safer setting for this manual LoRA path.

4. **Hardened C solved operational ambiguity.**
   - Current packaging failures/regressions should be interpreted as model/data issues unless Notebook C provenance fails.
